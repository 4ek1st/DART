## Tabs

- A tag search or artist profile opened from inside an artwork now shares one temporary tab with the next such search or profile, so the tab bar no longer fills up. Back returns to the previous page. Shift+click keeps the result in its own tab, and the middle mouse button opens it in a background tab.
- Open tabs has a new Close searches and profiles action that keeps pinned tabs, artworks and other sections. Searches typed in the search box still open in their own tab.
