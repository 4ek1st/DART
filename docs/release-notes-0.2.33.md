## Settings icons and stable keyboard focus

- Added consistent outline icons to all nine settings entries and the main
  section headings. The selected section uses DART's blue accent. Icons are
  embedded and need no additional downloads.
- Small windows use a compact grid without horizontal scrolling. Light, dark
  and List themes and English, Russian and German labels are supported.
- Kept the Updates entry as a stable part of settings rendering. Delayed privacy
  status responses and other settings refreshes preserve focus on that button.
  Its existing dialog and installation actions remain available, with Updates
  before Language in both visual and keyboard order.
