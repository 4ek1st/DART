# DART 0.2.61

- Group Favorite artworks by dragging one card onto another. Open a group to browse its individual works, merge groups, or ungroup them from the menu. Each work keeps its own likes, bookmarks and source identity.
- Favorites now uses the same cards, themes and interactions as the catalog, including galleries, keyboard shortcuts and background tabs.
- System picks in Favorites use existing likes and recommendation tag preferences. Liked works and actual viewing statistics remain separate.
- Artwork actions are available on right-click and in the more menu, including inside quick preview and fullscreen: save to Favorites, hide, download, copy an image, copy links, or copy all tags.
- Hidden artworks and their known copies stay hidden across restarts. Restore them in Content settings without losing likes or bookmarks.
- Remove separate Favorite star buttons. Tags and authors keep their own context actions.
- Fix menu closing when focus has just scrolled the page. Escape closes an open menu before the image viewer.

The Following feed retains the publication order fixed in 0.2.60. Existing profile data is preserved.
