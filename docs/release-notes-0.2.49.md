## Copy all artwork tags

- Right-click any artwork tag or its tag area and choose Copy to copy the full
  list, including collapsed tags and metadata from grouped copies.
- Tags use a comma and space separator, underscores instead of display spaces,
  and no leading hash marks. Confirmed creators come first, followed by
  copyright, characters and the remaining catalog tags, without duplicates.
- Copy uses the latest available detail metadata, independently of selected
  search tags. Clipboard success and failure feedback is available in English,
  Russian and German, with a fallback for restricted clipboard access.
