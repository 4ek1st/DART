# Clearer tag examples

- Tag hover previews show another artwork, excluding the currently open work, its grouped versions and confirmed file copies from other catalogs. Switching artworks also changes the preview cache context.
- Previously viewed examples still come first. Among available examples, character tags favor a single identified character; detail tags favor relevant focus metadata. Plain backgrounds and usable image dimensions provide small tie-breakers. This selection uses catalog metadata, not visual recognition.
- Grouped works use the thumbnail of a version that actually has the requested tag. Exact copies share one candidate slot, and a shared parent or publication alone cannot label a different scene as previously viewed.
- If no suitable viewed example exists, the first available catalog page supplies eligible alternatives. Existing content, source, creator and rating filters still apply, with bounded background loading and cancellation.
