## Faster collections and smoother artwork browsing

- Reduced pauses in Space preview and artwork navigation when many tabs are open.
- Reduced the first-preview pause in large Liked and Bookmarks collections. Grouped copies and artwork versions continue to use the shared duplicate checks.
- Faster repeated reads of saved collections and viewing history, with fewer unnecessary copies and reloads.
- Viewing artworks updates Favorites statistics while retaining already loaded manual characters, tags and artworks. Refresh and profile import still reload changed collections.
- Session saves are combined after interaction, with the latest tabs and pending activity preserved when closing or installing an update.
- Profile export and history/session saves no longer hold up independent settings reads. Export size limits, verified backups and atomic profile writes remain in place.
