# DART 0.2.59

- Added Favorites: browse favorite characters, tags and individual artworks.
- Switch independently between characters/tags and your own saved choices/system
  suggestions. Square covers show the latest artwork you actually opened.
- View your last 30 days of distinct-work activity. Source mirrors count once;
  older undated history is never converted into invented viewing statistics.
- Save artworks with the star in the viewer or artwork right-click menu. Artwork
  Favorites are independent of likes and bookmarks and survive restarting DART.
- Favorites use the existing content filters, themes and interface languages.

Viewing activity starts with this update. Existing likes, bookmarks and manual
favorite tags are retained. New viewing statistics and artwork Favorites are local
to this device. Install through DART's verified update button.
