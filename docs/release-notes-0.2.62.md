## Optional image upscaling

- Choose a default 2× or 4× enlargement in Settings → Image upscaling. Download the optional module once; DART connects it automatically.
- Right-click an artwork or use its ⋮ menu and choose Upscale. U also starts upscaling in the artwork viewer. The saved default is used immediately, without another window or a repeated choice.
- The original stays visible while processing. The result appears directly in the existing viewer; navigation, Space preview, fullscreen and zoom stay available. Original pixels, artwork dimensions, grouping, likes and bookmarks stay unchanged.
- The artwork menu can cancel processing, show the original or save the enlarged PNG as a separate file. Repeated processing reuses a checked local result.
- Work is bounded before image decoding and in the native queue. Cancelling a waiting job immediately frees its slot. Download, verification, storage and processing failures can be retried.
- Component files are checked against pinned hashes. Processing is local, and downloads start only on request. The module and its result cache are stored separately from the personal profile and signed application releases.
- English, Russian and German labels follow the interface language. Static images are supported; videos and animations are excluded.
