## Settings icons

- Added consistent outline icons to Content, Curation, Creators, Sources, Tabs,
  Appearance, Privacy, Updates and Language. The selected section's icon uses
  DART's blue accent. Matching icons also appear in the main settings headings.
- Icons are embedded, with no additional downloads or icon-library startup.
  Existing English, Russian and German labels remain available to assistive
  technology; decorative icons do not duplicate their names.
- Small windows use a compact grid of settings sections, keeping every section
  visible without horizontal scrolling. The layout supports light, dark and
  List themes, keyboard focus and reduced motion.
- Updates retains its existing dialog and installation flow. Its entry now
  appears before Language in both visual and keyboard order.
