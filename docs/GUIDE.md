# Руководство DART

[← На главную](../README.md)

## Запуск

Скачайте `DART.Windows.exe` из [последнего выпуска](https://github.com/4ek1st/DART/releases/latest)
и запустите его. EXE содержит интерфейс и .NET; отдельно нужен
[Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2).

В установленной версии используйте ярлык **DART** на рабочем столе или в меню
«Пуск». Он запускает активный выпуск и существующий профиль.

## Подключение каталогов

Откройте **«Источники и настройки» → «Источники»**.

| Каталог | Что нужно |
| --- | --- |
| Danbooru | Для обычного поиска ключ не требуется. |
| Gelbooru | Ваши `User ID` и `API key`. |
| Rule34 | Ваши `User ID` и `API key`. |
| Sankaku | Для функций, требующих входа, авторизуйтесь логином/email и паролем. |

Ключи и токены сохраняются с шифрованием Windows в вашем профиле. Пароль
Sankaku не сохраняется. Ограничения аккаунта и Plus продолжают действовать;
двухэтапная проверка входа Sankaku пока не поддерживается.

## Поиск и просмотр

Введите один или несколько тегов, выберите каталоги и рейтинг:
**«Обычные»**, **«NSFW»** или **«Все изображения»**. Можно переключать
**«Новые»** и **«Популярные»**. Следующие страницы загружаются при прокрутке.

Работы открываются во вкладках. Подтверждённые теги персонажей идут первыми
и выделяются зелёным; `original` выделяется фиолетовым. Чтобы искать по
сочетанию тегов, выделите их с **Ctrl + клик**, затем нажмите **Enter**.

Связанные варианты и найденные копии собираются в одну карточку, когда
данные источников позволяют подтвердить связь. В информации о работе
можно перейти к её записям в разных каталогах.

Видео открываются во встроенном плеере с перемоткой, звуком и полноэкранным
режимом. Поддержка конкретного формата зависит от кодеков WebView2.

## Лайки и рекомендации

Сердечко добавляет работу в закладки. Рекомендации учитывают теги сохранённых
работ, выбранные источники и рейтинг. Порядок подборки меняется при новом
открытии и обновлении; сохранённые работы и обнаруженные связанные копии
исключаются из рекомендаций.

Нажмите правой кнопкой по тегу:

- **Жёлтый приоритет** — показывать чаще.
- **Красный выключенный тег** — исключать из подборки.

Настройки сохраняются после перезапуска. В списке **Other** находятся теги
содержания; приоритетные и выключенные теги закреплены в начале.

## Подписки

Откройте профиль автора или страницу работы и нажмите **«Подписаться»**.
Подписка на подтверждённый тег художника объединяет доступные работы
поддерживаемых каталогов. Подписка на загрузчика остаётся отдельной.

Во вкладке **«Подписки»** новые работы отмечаются как **«Новое»**. Проверка
происходит при открытии вкладки и по кнопке **«Обновить»**; фоновых системных
уведомлений нет. Список авторов раскрывается через **«Управление подписками»**,
а лента работ продолжает загружаться при прокрутке.

## Обновления и данные

В зарегистрированной установке откройте **«Источники и настройки» → «Обновления»**.
Когда доступен проверенный новый выпуск, слева в строке вкладок появляется
кнопка установки. Она открывает список изменений и действие
**«Установить и перезапустить»**.

Обновления проверяют подпись, SHA-256, номер версии и историю выпусков.
Ошибка загрузки или проверки сохраняет активную версию. При запуске
портативного EXE напрямую новые версии можно скачивать со страницы
[выпусков](https://github.com/4ek1st/DART/releases).

У существующей установки личный профиль остаётся в
`Documents\ArtCatalog\Profile`. Название папки сохранено для совместимости:
в ней находятся закладки, подписки, вкладки, история и настройки. Закладки
сохраняют сведения о работе; для загрузки самого изображения нужен доступ
к источнику и интернет.

## Полезные клавиши

| Клавиша | Действие |
| --- | --- |
| Ctrl + K | Перейти к поиску. |
| Ctrl + клик по тегам, затем Enter | Искать выбранное сочетание тегов. |
| Esc | Закрыть подсказки поиска. |
| Стрелки при фокусе на строке вкладок | Переключить вкладку. |
| Delete при фокусе на строке вкладок | Закрыть выбранную вкладку. |

Если что-то не работает, [создайте issue](https://github.com/4ek1st/DART/issues)
с версией программы, названием каталога и шагами воспроизведения.
Не прикладывайте пароли, ключи API или файлы личного профиля.
