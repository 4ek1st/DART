# DART for Android

Самостоятельное Android-приложение. ПК для работы не требуется. Android 8.0+
(API 26), English / Русский / Deutsch, собственные цвета и оформление ArtCatalog.

## Установка

Готовый подписанный APK: `outputs/ArtCatalog-Mobile-0.1.12.apk`.
Перенесите его на телефон, откройте и разрешите установку из приложения,
которым открыли файл. Последующие APK устанавливайте поверх существующего
приложения, чтобы сохранить его локальный профиль.

В «Моё → Настройки → Источники» можно добавить свои User ID и API key для
Gelbooru и Rule34. Danbooru использует публичный API. Доступность каждого
источника зависит от его правил доступа и подключения телефона.
Ошибки источников показаны в ленте; повторная загрузка доступна по нажатию.

Sankaku доступен среди источников. В «Моё → Настройки → Источники → Sankaku»
можно войти по логину/email и паролю или выйти. Пароль не сохраняется; токены
доступа и обновления зашифрованы Android Keystore и не включены в экспорт.
При ограничении доступа приложение предлагает авторизацию и открывает форму
в настройках. Обычный лимит запросов, неправильный пароль и ограничения Plus
получают отдельные сообщения. Двухэтапный вход пока не поддерживается.
Ограничение нескольких работ одного источника не прерывает продолжение
доступных рекомендаций и каталога из остальных источников.

Поиск, новые работы, закладки, история, рекомендации, подписки на теги
художников, персонажи и группы вариантов используют существующие экраны.
«Популярные» Sankaku запрашиваются с `order:popularity` и сохраняют порядок
сайта; оценки разных сайтов не меняют этот порядок. Временные ссылки на медиа
обновляются при открытии работы и перед просмотром/скачиванием оригинала.

## Интерфейс

- Главная: горизонтальный рейтинг и сетка рекомендаций в две колонки.
- Поиск: темы, история запросов и подсказки тегов.
- Новое: работы художников из подписок или общая лента новых работ.
- Закладки: локально сохранённые работы, сердечко доступно на карточке.
- Моё: отдельные «Понравившееся» и «Закладки», история, подписки, источники,
  импорт и экспорт профиля.
- Иллюстрация: все изображения одной работы стоят подряд в вертикальной ленте,
  затем идут действия, художник, теги, другие работы автора и похожие
  иллюстрации. Двойной тап по любому изображению ставит лайк всей работе;
  масштабирование в полноэкранном просмотре работает двумя пальцами.
  Видео открывается отдельным нажатием; полноэкранный плеер запускает его
  автоматически, в том числе после свайпа с фотографии на видео.
- Свайп вправо по всему экрану работы — следующая иллюстрация, влево — предыдущая.
  Кадры одной работы листаются вертикально, а горизонтальный свайп сразу
  открывает соседнюю работу из ленты. Рейтинг, поиск и работы автора продолжают
  загружать следующие страницы прямо из просмотра.
- Быстрые переходы сохраняются в очереди. Следующая страница загружается при
  необходимости; текущая работа остаётся видимой до подготовки следующего
  изображения. При свайпе вся страница плавно сдвигается в нужную сторону за
  260 мс. Ошибку загрузки можно повторить следующим свайпом.
- Похожие работы и профиль художника подгружаются при прокрутке; профиль
  открывается по имени художника, подписка относится к его собственному тегу.
- Первые восемь тегов видны сразу, остальные раскрываются кнопкой. Персонажи
  отмечены зелёным, франшизы и `original` — фиолетовым, как в настольном приложении.
- Подписка на художника использует подтверждённый тег. Загрузчик имеет свой
  профиль и подписку, привязанную к конкретному источнику. В «Новое → Подписки»
  новые после первого просмотра работы помечаются; отметка снимается при открытии.
- Несколько подтверждённых копий объединяются в одну работу без повторяющихся
  карточек. Под действиями сразу показаны художник и сведения об атрибуции.
- Варианты собираются по публикации, связям parent/child и компактным сериям
  загрузки. Для Rule34 дополнительно используется сходство миниатюр с проверкой
  загрузчика и тегов. Число изображений видно на карточке; внутри работы они
  идут вертикально, и каждое можно открыть на весь экран.

## Настройки и загрузка

В «Моё → Настройки» доступны разделы «Контент», «Авторы», «Источники» и «Вкладки»:
фильтры AI-generated/AI-assisted, furry, точные исключённые теги, скрытие
просмотренного и сохранённого, скрытые авторы, приоритет подписи
художника/исходной ссылки/загрузчика, приоритетные и исключённые теги
рекомендаций, оформление, защита от снимков экрана и режим открытых работ.
Открытые работы можно искать, закреплять и закрывать.

Приложение показывает сохранённую ленту до ответа сети. Общие списки обновляют
только изменившиеся строки без анимации повторного появления. Карточки получают
постоянное место сразу после получения сведений, а превью появляются независимо
с коротким плавным переходом. Медленная миниатюра не задерживает остальную ленту.
Уже показанная обложка сохраняется при добавлении копии из другого каталога,
а позиция просмотра — при объединении дубликатов выше текущего места.
Окно загрузки движется вместе с текущей
позицией и готовит до 24 карточек ниже экрана; следующая страница запрашивается
заранее. Превью и большие изображения имеют отдельные ограниченные кэши.
Карточки Danbooru используют предоставленный API вариант до 720 px; большая
работа догружается поверх сохранённого превью. Скорость первой загрузки нового
контента зависит от источника и соединения телефона. При холодном открытии
сначала запрашивается маленькое превью, затем параллельно — полный файл;
открытие работы имеет отдельные ограниченные рабочие потоки и приоритет перед
фоновыми миниатюрами. При догрузке качества сохраняются масштаб и место просмотра.

Видеоработа показывает настоящую обложку и кнопку воспроизведения. В плеере
обложка остаётся до первого выведенного кадра. Загрузка, пауза и ошибка имеют
свои состояния; после ошибки можно повторить попытку, нажав на сообщение.

Новые работы подписок проверяются при открытии/обновлении ленты.
Подписки собираются в общую ленту: сначала новые после предыдущей успешной
проверки работы, затем дата публикации. При одинаковой дате авторы чередуются.
Уже видимые карточки и пройденная часть полноэкранного просмотра сохраняют
свой порядок, пока ещё не показанная часть принимает поздние ответы источников.
Запросы охватывают свежие страницы разных подписок перед переходом к старым.
Успешная проверка одного каталога не отмечает проверенными остальные каталоги.
Фоновых push-уведомлений нет. Приложение сохраняет собственный профиль на
телефоне. Экспорт через системный выбор файла включает закладки, подписки,
историю, поисковые запросы, параметры контента и отметки просмотренного.
Импорт объединяет данные и принимает JSON
закладок настольного ArtCatalog. Ключи API зашифрованы Android Keystore
и не включаются в экспорт. Настольная программа и её данные не изменяются.
Перед импортом показаны выбранный файл и количества записей. Отметьте согласие
и нажмите «Перенести»; изменение выбора настроек требует нового согласия.

## Проверка на Windows

Двойной щелчок по `Start-Android.cmd` открывает видимое окно Android Emulator,
устанавливает последний подписанный APK из `outputs` и запускает ArtCatalog.
На этом ПК SDK и виртуальный телефон ArtCatalogPhone уже подготовлены.
Скрипт использует аппаратное ускорение CPU и графику видеокарты.
Повторный запуск обновляет APK с сохранением профиля эмулятора.

Мышь заменяет касания: щелчок — нажатие, удержание и перетаскивание — свайп.
Кнопки эмулятора позволяют вернуться назад и повернуть экран. Это отдельный
виртуальный телефон; его ключи, закладки и история отличаются от физического
телефона. Для точного воспроизведения ошибок физического устройства можно
подключить его по USB и отображать его экран на ПК.

## Сборка

Требуются полный JDK 17+ (проверено с JDK 21), Android SDK platform 35 и
build-tools 35.0.0. Gradle 8.14 включён через wrapper; AGP 8.10.1.

```powershell
.\build-apk.ps1 -SdkPath 'C:\path\to\Android\Sdk' -JdkPath 'C:\path\to\jdk'
```

Скрипт выполняет тесты, собирает release, выравнивает APK, подписывает его
и проверяет подпись. Постоянный ключ подписи лежит вне репозитория в
`%LOCALAPPDATA%\ArtCatalogBuild\signing`; пароль защищён Windows DPAPI.
Сохраните ключ и доступ к паролю для будущих обновлений. Без прежнего ключа
Android не разрешит установку обновления поверх приложения.

## Проверка

Сценарии и ограничения проверки записаны в `docs/verification-0.1.12.md`.
Тестовые нейтральные пейзажи находятся только в debug source set.
Они включаются явным `--ez qaFixtures true` при запуске debug APK и
не входят в release APK. Пользовательский APK обращается к реальным API.

## Windows ↔ Android

Use **My → Settings → Profile transfer** (or **Моё → Настройки → Перенос профиля**) to export a DART-profile JSON file. Transfer this file to the other device, open Settings → Profile transfer there, preview the counts and choose Merge. Import adds likes, bookmarks, subscriptions, viewed identities and tags; it never replaces the other profile. Content and curation settings are optional. Credentials and account sessions are not transferred. Windows support starts with DART 0.2.54.

See `docs/release-notes-0.1.11.md` for the shared logic and Android-specific controls. Install updates over the existing app; do not uninstall or clear its data.
