# Android 0.1.16 verification

Scope: Android viewer direction/responsiveness, repeated-like feedback, pinch behavior and imported saved Sankaku previews. Package and signing identity are preserved. The in-app updater remains absent.

Native regression checks run on an owned hidden API35 ArtCatalogQA emulator, separate user 10, with neutral debug fixtures. The personal phone/profile and Windows window are not controlled. Before the fix, the native checks reproduced reversed gestures, a jump after lifting the first pinch finger, delayed repeated-heart feedback, a ready neighbor blocked by the busy grouping worker, and a repaired Sankaku URL left unbound in Liked. The first bookmark-state probe was corrected to be idempotent; it did not establish a production collection-loss bug.

After the fix, native checks confirm left/next and right/previous, stable pointer handoff, two-finger center translation of 20 px, and preserved zoom/subject after a quality upgrade. Repeated like handling took 0-1 ms in the neutral fixture and its animation was visible within the 100 ms observation. A ready neighbor was open at the 132-136 ms observation while the grouping executor was deliberately held for up to two seconds. These are controlled emulator observations, not phone/network benchmarks. Cached navigation also skips a newly confirmed duplicate. A renewed saved Sankaku preview rebinds in place, retaining both its like and bookmark.

Existing native navigation regressions pass for five queued inputs, slow/filtered page boundaries, forward/reverse moves, failed-media continuation, retry and cancellation cleanup. The deferred-provider scenario passes without changing cursor positions, flooding requests or preventing a reverse move. A separate cold loopback-video check sends actual adb swipes using native UI-tree bounds: left opens the next image before any decoded video frame, and right returns to the previous video. The video's accessibility description is updated before its early playback return. The remaining 260 unit tests pass; release lint reports 0 errors and 28 warnings.
