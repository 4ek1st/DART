# DART for Android 0.1.16

- Swipe your finger left for the next artwork and right for the previous one. Detail pages, fullscreen images and videos use the same direction, with matching page animation.
- Published neighboring artworks remain usable while background feed grouping is busy. Confirmed copies are skipped, and page lookahead uses the latest published source list.
- Repeated double-tap likes show their heart immediately instead of inheriting the previous fade-out delay. Likes remain saved locally in the background.
- Pinch zoom follows the center of both fingers. Lifting one finger keeps the image still; full-quality image upgrades preserve the selected subject and zoom. Double-tap liking no longer also enables Android's one-finger quick zoom.
- Imported Sankaku previews refresh in the open Liked, Bookmarks and History pages. A failed visible thumbnail can trigger exact-post recovery even when another old media URL has not been tried yet. Saved identities and separate like/bookmark states are preserved.

Install this APK over the existing app to preserve the local profile. The Android in-app updater remains removed; use the ordinary release link in About for manual downloads. Whether Google Play Protect changes its classification must be checked on the device and is not established by these local tests.
